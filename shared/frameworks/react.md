## Quy tắc React

- Tuân theo pattern component/state hiện có; tái sử dụng design system chuẩn và
  semantic token.
- Thể hiện rõ các trạng thái loading, error, empty, responsive và accessibility.
- Đặt durable state tại component/feature sở hữu nó; tránh abstraction chỉ dùng
  cho một component hoặc call site.
- Chạy typecheck, lint hoặc build hẹp nhất phù hợp.
